## Entry

> I came, I saw, I left a one-star review on my way out.

One line, 54 characters. A Veni Vidi Vici exit — the grandest possible departure,
spent on the pettiest possible review. The joke lands because the scale is
backwards: conqueror's Latin, customer's complaint.

## How it works

`main.ts` (Node 22) writes the entry line to `/output/entry.txt`.

```sh
npx tsx main.ts
```
